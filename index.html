MY ACADEMIC WORK

My Projects

These are two separate academic project entries developed with my groupmates. Each project focuses on a different area of computer science: database management and web design.

PROJECT 01

4Seasons Resort Database Management System

DATABASE MANAGEMENT SYSTEM

This academic group project focuses on the database design and management of the 4Seasons Resort Reservation System. Its purpose is to organize and store important information needed for resort operations and customer reservations.

We designed a relational database structure that connects different records through primary keys and foreign keys. This helps organize information and maintain relationships between database tables.

Project Features and Concepts:
  • Database and table creation
  • Customer account information
  • Room and reservation records
  • Administrator information
  • Primary keys and foreign keys
  • Entity Relationship Diagram (ERD)
  • Relational database relationships

My Learning Experience: This project helped me understand database organization, data relationships, database structure, and how information is stored and managed in a system.

PROJECT 02

4Seasons Resort Website Design and Development

WEB DESIGN & DEVELOPMENT

This academic group project focuses on designing and developing the 4Seasons Resort website. The website provides a digital platform where customers can explore the resort, access their accounts, and manage their reservation-related information.

We created a user-friendly interface with a resort-themed design, organized navigation, and customer portal. The website includes login and registration pages and a customer dashboard.

Website Features:
  • Homepage and navigation menu
  • Login and registration interface
  • Customer dashboard
  • Reservation information display
  • Resort rooms and services section
  • Customer account interface
  • Responsive website layout

My Learning Experience: This project helped me improve my understanding of website layout, user interface design, front-end development, and creating accessible and organized web pages.
